# Pi image, hub networking, GitHub releases and version staging: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** a flashable Raspberry Pi image of the hub, with networking for every set-up in DEPLOYMENT.md section 4, upgrades from GitHub releases, and staging of the hub version in the Facility Hub app.

**Architecture:**
- **Upgrades:** the hub reads the country's choice from `facility-hub-admin/release` on central, and the release itself from GitHub, signed with a key built into the binary.
- **Networking:** a new `internal/netsetup` drives NetworkManager through `nmcli`, behind an interface so tests use a fake.
- **The image:** shell scripts rebuild the official Pi OS Lite image without loop devices or mounts. The app gets a version page that writes the choice.

**Tech Stack:**
- Go 1.x, the existing packages.
- bash, debugfs, mkfs.ext4, mtools, sfdisk, xz.
- NetworkManager (`nmcli`) on Pi OS trixie.
- The App Platform app (TypeScript, React 18, `@dhis2/ui`, TanStack Query 4, jest).
- GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-19-pi-image-design.md`

## Global Constraints

- **Base image:** Raspberry Pi OS Lite 64-bit, trixie, `2026-10-06`, checked against its published SHA-256: `downloads.raspberrypi.com/raspios_lite_arm64/images/raspios_lite_arm64-2026-10-06/2026-10-06-raspios-trixie-arm64-lite.img.xz`.
- **Build constraints:** no loop devices or mounts (none in this sandbox, often none in CI containers). Run as root on an arm64 host.
- **Release source:** `https://github.com/dhis2-utils/poc-data-proxy/releases/download`, tag `v<version>`. The source and the ed25519 public key are set at build time with `-ldflags -X`, never in `hub.yaml`.
- **The country's choice:** `facility-hub-admin/release` = `{"version": "0.3.0", "pilotHubs": ["hub-…"], "percent": 10}`. Public read, hub managers read-write, written through `writeAdminEntry`.
- **Hub names:**
  - host name `dhis2`;
  - setup Wi-Fi "Hub-<hub ID>", WPA2, a 12-character password without look-alike characters;
  - NetworkManager connections `hub-setup`, `hub-wifi`, `hub-facility`;
  - the setup Wi-Fi returns after 60 seconds with no network at boot, and after 15 minutes without a joined network.
- **Windows:** no `nmcli`. Networking is off unless `hub.yaml` has `network: networkmanager`.
- **Repo rules** (AGENTS.md):
  - `go vet ./...` and `go test ./...`;
  - `go test -race` on `internal/e2e`, `internal/live`, `internal/tracker`, `internal/store`;
  - commits without a `Claude-Session` trailer;
  - test suites run under `env -u GITHUB_TOKEN`.
- **Go toolchain:** `export PATH=$HOME/sdk/go/bin:$PATH GOPROXY=direct GOSUMDB=off`. Work in `~/work/hub`, and push the branch to `/Users/olavpo/Repos/PoC/poc-data-proxy`.

## Review Focus

1. **Join a Wi-Fi with a wrong password:** the setup Wi-Fi must come back within about a minute and show "wrong password". A hub must never end up with no network and no setup Wi-Fi. Pinned in Task 6: `TestJoinFailsBringsSetupBack`.
2. **A cable plugged in while the setup Wi-Fi is on:** the setup Wi-Fi stops. In case C (`hub-facility`), it must not stop the facility's Wi-Fi. Pinned in Task 6: `TestCableStopsSetupNotFacility`.
3. **A release choice naming a version older than the hub's, or one that failed here before:** no upgrade, no loop. Pinned in Task 1: `TestNoDowngradeNoRetry`.
4. **The app's step count disagreeing with which hubs actually upgrade:** a shared table. Pinned in Task 2: `stages.json`, used by both test suites.
5. **An image whose `PARTUUID`s don't match `cmdline.txt` or `fstab`:** it won't boot, which nothing here can catch except the check. Pinned in Task 8: `check.sh` compares them.

  - `Tick(ctx)`, every 10 s;

  - `Join(ssid, password string) error`;

  - With no uplink and no `hub-wifi` for 60 s after start, or `hub-wifi` lost for 15 minutes: scan, keep the list, write `<DnsmasqDir>/hub-captive.conf` (`address=/#/10.42.0.1`), and add and bring up `hub-setup`:

    - `wifi-sec.key-mgmt wpa-psk`;
    - autoconnect off.
