If nothing happens, this device does not trust the facility's hub yet. Follow the steps below once.

Trust the facility's hub on this device (once)

The hub encrypts everything with its own certificate. Install it once on each device, then this page opens DHIS2 by itself.

{{.Fingerprint}}

Android

  1. Tap Download the hub's certificate above.
  2. Open Settings › Security and privacy › More security settings › Install from device storage › CA certificate (names differ a little between phones; search Settings for "CA certificate").
  3. Android warns "Your privacy is at risk": tap Install anyway. The certificate only works for this hub.
  4. Enter your screen lock (Android needs one), and pick dhis2-hub.crt from Downloads.
  5. Come back to this page and reload it.

iPhone and iPad

  1. Open this page in Safari and tap Download the hub's certificate; allow the profile.
  2. Open Settings › General › VPN & Device Management, tap the profile and Install.
  3. Open Settings › General › About › Certificate Trust Settings and switch on full trust for "DHIS2 facility hub". Without this step Safari keeps warning.
  4. Come back to this page and reload it.

Windows

  1. Download the certificate and open it; choose Install Certificate.
  2. Choose Place all certificates in the following store, then Trusted Root Certification Authorities, and finish.
  3. Firefox: Settings › Privacy & Security › Certificates › View Certificates › Authorities › Import.
  4. Restart the browser and open this page again.

Mac

  1. Download the certificate and open it; Keychain Access adds it.
  2. In Keychain Access, open "DHIS2 facility hub", expand Trust and set When using this certificate to Always Trust.
  3. Open this page again.

Already done? Continue to DHIS2. Never click through a certificate warning for the hub: ask your focal point instead.
